# Nachub für uns
Hier liegen die Odoo Module für Nachschub für uns.
Nachschub für uns ist ein System, um in Einkaufsgemeinschaften(EKG) beim Bio-Großhandel zu bestellen. Die Bestellung beim Großhandel wird dabei über eine zentrale Instanz (Nachschub für Markus) abgewickelt. Die Bestellungen werden dann per Dropship an die EKGs geliefert.
